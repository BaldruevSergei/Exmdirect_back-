Exmdirect_back-

Exmdirect_back- — это серверная часть образовательной системы Exmdirect, предназначенной для создания, проведения и автоматической проверки тестов. Платформа ориентирована на школы и учителей, желающих использовать цифровые технологии для оценки знаний учащихся.

Система вдохновлена сервисами Индиго и ЯКласс, но включает уникальные функции:
	•	Интеграция с Telegram-ботом
	•	QR-коды для идентификации учеников
	•	Генерация до 30 уникальных вариантов тестов
	•	Механизмы защиты от списывания (например, запрет смены вкладок)

Основной функционал
	•	Регистрация и авторизация учителей и учеников
	•	Импорт КТП и рабочих программ (Excel)
	•	Назначение учеников и классов
	•	Создание тестов на основе тем и целей
	•	Генерация уникальных вариантов заданий
	•	Проверка работ и выставление оценок
	•	Подробный отчёт по ошибкам
	•	Верификация результатов по QR-коду
	•	Telegram-бот: уведомления, сканирование QR, авторизация

Технологии
	•	Java 17+
	•	Spring Boot, Spring Security (JWT)
	•	Spring Data JPA
	•	PostgreSQL
	•	Maven
	•	Lombok
	•	REST API

Запуск проекта

Требования
	•	Java 17+
	•	PostgreSQL
	•	Maven

Конфигурация (application.yml)

spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/exmdirect
    username: postgres
    password: your_password
  jpa:
    hibernate:
      ddl-auto: update
    show-sql: true

Сборка и запуск

mvn clean install
mvn spring-boot:run
