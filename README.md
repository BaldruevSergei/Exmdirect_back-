Exmdirect — это серверная часть образовательной платформы для онлайн-тестирования, аналогичной системам Индиго и ЯКласс. Система позволяет проводить контроль знаний учащихся в интерактивной форме с автоматической проверкой и учётом результатов.

Основные возможности
	•	Регистрация и авторизация пользователей (учителя, ученики, администраторы)
	•	Создание тестов и контрольных работ
	•	Автоматическая генерация вариантов заданий
	•	Проверка ответов и выставление оценок
	•	Просмотр результатов и статистики
	•	Интеграция с Telegram-ботом для быстрой аутентификации и уведомлений
	•	Работа с QR-кодами для быстрой проверки тестов
	•	Защита от списывания (ограничение вкладок и времени)

Запуск проекта

Требования
	•	Java 17+
	•	Maven
	•	PostgreSQL

Конфигурация базы данных

Файл application.yml:

spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/exmdirect_db
    username: your_user
    password: your_password
  jpa:
    hibernate:
      ddl-auto: update
    show-sql: true

Установка и запуск

mvn clean install
mvn spring-boot:run
